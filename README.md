# Quantum-hub website

The public Quantum-hub website: a responsive, multi-route storytelling experience built for Cloudflare-compatible deployment with vinext.

## Local preview

```bash
npm install
npm run dev
```

## Verification

```bash
npm test
```

The verification command compiles the production bundle, server-renders every public route, and checks that the production brand assets are present.
